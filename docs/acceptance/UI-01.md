# UI-01 — перенос проверенной оболочки

Статус: **ожидает финального CI новой копии и явного решения владельца**. Формальная приёмка/merge не выполнены. UI-02/UI-03 и функциональная фаза не начаты.

Сохранены без изменения код Kotlin, дизайн-токены и компоненты, navigation shell, ресурсы/launcher, зависимости, Wrapper и все тестовые методы/assertions. APK ru.gleb.readingjournal, versionName 0.1.1-ui01, versionCode 2. Изменены только редакции документации, безопасный gitignore и организация CI. Перечень — [FILES](../FILES.txt).

Все шесть исправлений реализованы:

1. Достижения — линейная медаль с двумя лентами.
2. Библиотека — корешки книг с наклонным томом.
3. Настройки — симметричная шестизубая шестерёнка.
4. Заглушки трёх вкладок центрированы между панелями с прокруткой при недостатке места.
5. Settings Back — полноразмерное горизонтальное смещение без scale; predictive Back учитывает оба края, отмену и завершение; отдельный Scaffold каждого destination сохраняет viewport. Системные анимационные настройки соблюдаются.
6. Launcher — мягкий скруглённый книжный знак с системной adaptive-маской.

В MIGRATION-01 владелец сообщил, что **все шесть пунктов повторно проверены им на Samsung Galaxy A55**. Это физическая визуальная проверка владельца, а не проверка устройства агентом. Отдельные новые проверки TalkBack/всей матрицы масштабов не приписываются этому сообщению.

До переноса полный suite проверенного кода прошёл: 3 JVM и по 10 Compose-тестов API 26/35/36. Это историческое подтверждение идентичного кода, **не результат нового CI**. Прежние логи, artifacts и связанные технические отчёты не перенесены.
