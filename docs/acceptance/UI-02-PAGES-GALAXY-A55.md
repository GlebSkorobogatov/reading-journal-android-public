## Перед установкой

Получить APK, точный Head, Full run/artifact ID, SHA-256 и результат сравнения сертификатов из описания нового PR/итогового отчёта. Версия **0.2.1-ui02-pages (4)**, applicationId `ru.gleb.readingjournal`. Сверить SHA-256 самого APK. Если сертификат отличается от UI-01, обычное обновление может не установиться; не удалять приложение/данные автоматически.

Записать Android/OneUI, тему, fontScale, ориентацию и проверяемый SHA. Только синтетические данные. Сценарии доступны: **Настройки → Каталог компонентов · debug → Сценарии главной · debug**. Восемь сценариев: Пустой дневник; Одна книга; Несколько книг; Закреплённые книги; Книга без записанных страниц; Закладка ниже рубежа; Исторические прочтения; Длинные названия. После выбора открывается Главная.
