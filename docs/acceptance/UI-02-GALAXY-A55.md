# Galaxy A55 — ручная приёмка UI-02

Статус: **NOT RUN — ожидает владельца**. Автоматические снимки эмуляторов и Preview не являются физической проверкой A55. Merge и UI-03 не разрешены.

## APK и условия

Использовать debug APK `ru.gleb.readingjournal`, **0.2.0-ui02 (3)** из успешного полного CI итогового Head UI-02. Прямые ссылки, ID запуска и независимо проверенная SHA-256 самого APK публикуются в [отчёте UI-02](UI-02.md) и PR после фактической загрузки. Распаковать артефакт и проверить `app-debug.apk` по его `SHA256SUMS.txt`; сумма ZIP — другая величина.

Заполнить перед проверкой: дата ___; Android ___; One UI ___; Head ___; CI ___; SHA-256 APK ___; режим системной навигации ___. Совместимость debug-сертификата не гарантируется. При отказе обновления из-за подписи остановиться и сообщить; приложение и данные автоматически не удалять.

Это визуальный прототип: длительность таймера фиксирована, реальные часы, сеансы, XP и библиотека не сохраняются. Фикстуры привязаны к 12 ноября 2026 г. Условные страницы и даты не являются личной историей владельца.
