## Реализация

1. Вертикальная LazyColumn: все читаемые книги без ограничения, закрепление/ручной порядок, остальные по последнему чтению; исходные Fit-обложки/типографические заглушки, полные названия/авторы, рубеж и страницы.
2. Единственный глобальный mock-таймер: старт, пауза, продолжение, завершение; фиксированная длительность 18:40, терракотовая рамка, мини-панель над навигацией, возврат с других вкладок к управлению. PENDING блокирует только свою книгу, «Не помню страницы» снимает блокировку, но не создаёт ноль.
3. Крупная XP-карточка: оригинальная локальная Canvas-иллюстрация открытой книги, пути и звезды. Основной пример — уровень 8 «Ученик», общий XP 2520, текущие 70/550 до уровня 9. `T(8)=2450`, `C(8)=550`; данные согласованы с утверждённой моделью, не рассчитываются настоящим движком. Пустой пример — уровень 1 / 0 XP; одна книга — уровень 1 / 25 XP.
4. Три фиксированные метрики Время/Страницы/Текущая серия; адаптивная вертикальная компоновка при крупном тексте. Шесть периодов на заранее подготовленных снимках; глобальные XP и серия от периода не зависят.
5. Пять фиксированных секций с видимыми сводками, открыта максимум одна. Внутри: столбцы времени/страниц, день/неделя/месяц и интервалы; независимые маркеры количества/точности даты и группа «Без точной даты»; годовой heatmap; горизонтальное сравнение всех читаемых книг с нулевыми; простой список завершённых циклов; скорость/прогноз часов/недостаточность данных; шесть рекордов и охват.
6. Десять deterministic fixtures через существующий debug-каталог. Ключевые визуальные выборы, порядок pin и состояния mock-таймера — ViewModel/StateFlow и ограниченный SavedStateHandle; пользовательская библиотека не создаётся. Прокрутка — saveable state Compose/Navigation. Новый процесс открывает Главную по принятому контракту MainActivity.
