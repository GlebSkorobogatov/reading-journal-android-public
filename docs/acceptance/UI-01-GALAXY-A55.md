# Galaxy A55 — приёмка UI-01 после переноса

APK: ru.gleb.readingjournal, 0.1.1-ui01 (2), debug. Перед установкой скачать артефакт **нового успешного полного CI**, распаковать и сверить SHA-256 самого app-debug.apk с SHA256SUMS.txt. Не путать с суммой ZIP. Номер run, Head и checksum записать в результат.

## Подпись и установка

ApplicationId и версия сохранены. Новый GitHub runner может создать другой debug keystore, поэтому совпадение подписи с уже установленной сборкой **не гарантировано**. Ключи не переносятся и не публикуются. Для сравнения при наличии обоих APK можно выполнить Android SDK `apksigner verify --print-certs <APK>` и сопоставить SHA-256 сертификатов; для APK, установленной владельцем, сравнение ещё NOT RUN. Локальная прежняя и новая сборки имеют одинаковый сертификат, но это не подтверждает совпадение с прежней CI APK на телефоне. Подпись сертификата и checksum файла — разные величины.

При INSTALL_FAILED_UPDATE_INCOMPATIBLE либо отказе Android обновить приложение остановиться и сообщить о несовместимости. Не удалять установленное приложение/данные автоматически. В UI-01 постоянное хранилище ещё не реализовано, но решение о переустановке всё равно принимает владелец. Стабильная release-подпись относится к REL-01, не вводится при переносе.

## Проверки владельца

Владелец уже подтвердил повторное прохождение всех шести визуальных пунктов прежней сборки. Для новой сборки зафиксировать установку/подпись и smoke-проверку:

1. Холодный запуск открывает Главную. Три вкладки переключаются; выбранная обозначена линией и доступной семантикой.
2. Иконки книг/медали/шестерёнки узнаваемы, линия и пропорции согласованы; launcher мягкий, маска One UI не обрезает знак.
3. Заглушки по центру доступной области между панелями. Никаких полноценных экранов следующих задач нет.
4. Из Библиотеки открыть настройки и вернуться стрелкой, кнопочным Back и жестом с каждого края. На неполном жесте настройки полноразмерны; отмена оставляет настройки, завершение возвращает Библиотеку. С корневой вкладки Back ведёт на Главную, с Главной — в Android.
5. Светлая/тёмная/системная темы. В системном режиме сменить системную тему и проверить следование. Обычный поворот/возврат из фона сохраняет необходимый контекст, новый процесс открывает Главную.
6. Debug-каталог доступен из настроек, четвёртой вкладки нет. Проверить enabled/disabled/pressed/focused/selected/error/unknown, диалог и нижнюю панель.
7. Обе темы × fontScale 1.0/1.3/1.5/2.0 × портрет/альбом: длинные русские строки, важные действия и системные insets доступны; при недостатке места прокрутка, текст не уменьшается принудительно.
8. TalkBack: порядок фокуса, подписи и состояния. Жестовая/кнопочная навигация, системное снижение движения. По окончании вернуть исходные настройки телефона.

Передать PASS/FAIL с Android/One UI, APK checksum/run/Head, темой/масштабом/ориентацией и шагами замечаний. Новые результаты не считаются выполненными заранее. Физическая проверка и явное принятие UI-01 — отдельные действия; ни одно не разрешает UI-02 или merge автоматически.
