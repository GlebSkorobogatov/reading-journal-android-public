# MIGRATION-01 — подготовка новой копии

Статус: **MIGRATION-01 — подготовлено к безопасной публикации, ожидает решения владельца**. Код и локальные проверки сохранены; GitHub CI не запускался по указанию владельца. Точные SHA, ссылка на Draft PR и результаты удалённой проверки фиксируются в описании PR и отчёте владельцу после отправки. Видимость меняет только владелец. Это инфраструктурная задача, не приёмка UI-01 и не разрешение UI-02/UI-03.

## Состав и редакционные границы

Перенос выполняется через явный allowlist файлов, отдельно от прежнего checkout и Git-истории. [FILES.txt](../FILES.txt) перечисляет комплект. Сохранены все семь основных документов, действующие требования v2.04, У1–У8, А1–А4, TZ-01, каталог А3, ADR-01–10, нормативное приложение А UI_DESIGN_SPEC и точный текстовый дизайн-референс.

Исключены исторические интервью/снимки и архивы, старые технические отчёты/логи/артефакты, локальные данные и настройки, ключи и credentials. Старая Git-директория и refs не копировались. Существующий архив не изменяется. Копируются только три необходимых бинарных ресурса: два лицензированных шрифта и Wrapper JAR; его ZIP-содержимое проверяется отдельно.

Редакционные изменения: новый адрес репозитория, текущий статус, пути и реестр источников; нормализованы концевые пробелы/пустые строки Markdown для git diff --check; удалены прежние суммы исходных комплектов; созданы новые SHA256SUMS; исторический §11 v2.04 заменён пояснением, действующие §§1–10, 12–15 сохранены. У1–У8 вынесены точной действующей выдержкой без старых вариантов. Дорожная карта содержит прежнюю последовательность и актуальную декомпозицию IMPLEMENTATION_PLAN. Продуктовые IDs, алгоритмы, пороги и дизайн не менялись.

Побайтово сохранены Kotlin main/debug/test/androidTest, все методы/assertions, Theme/Components/LineIcon/navigation, ресурсы и мягкий launcher, зависимости, каталоги версий, Wrapper и launchers, applicationId ru.gleb.readingjournal, versionName 0.1.1-ui01, versionCode 2. Проверка выполняется по всем явно выбранным исходным файлам. Gitignore дополнен исключениями Python bytecode, локальных конфигураций/credentials, ключей, баз и скачанных APK/logs; приватные файлы также отклоняются scope-проверкой CI. Сравнены 39 неизменённых файлов приложения/Gradle/лицензий/исходного JUnit helper; все 176 определений PRD и 15 защищённых нормативных блоков сохранены (для Markdown сравнение нормализует только концевые пробелы). Изменения CI и документации рассматриваются отдельно.

## Конфиденциальность и ограничения

В публичном комплекте не сохраняются персональные адреса коммитов, данные оплаты/авторизации, идентификаторы облачных сред, старые журналы или ссылки на прежние артефакты. Аудит включает Gitleaks и содержательный анализ выбранных файлов/документов, Gradle JAR и шрифтов, workflow/скриптов и будущего текста PR. Это не абсолютная гарантия отсутствия секретов; будущие CI outputs требуют отдельного аудита после выполнения. Независимый git init выполнен; прежние commits/tags/refs, объектные packs и alternates не импортировались. Новые author/committer используют один подтверждённый noreply аккаунта владельца. Совпадение blob-ID идентичных файлов закономерно и не является импортом истории. Wrapper JAR распакован: 35 записей, CRC исправна; проверены 60 записей метаданных двух шрифтов. Изображений в комплекте нет. Известный личный email в содержимом не найден. Синтетический адрес тестовых Git fixtures использует зарезервированный домен example.invalid и не является адресом владельца.

Шрифты имеют SIL OFL в licenses. Отдельная лицензия на код/документацию не выбиралась автоматически: публичная видимость сама по себе не предоставляет произвольных прав использования. Пользовательских изображений/записей и старых screenshots в комплекте нет.
