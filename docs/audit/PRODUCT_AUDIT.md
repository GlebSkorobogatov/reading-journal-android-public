### Технические риски (способ реализации делегирован Codex, проверяемые гарантии обязательны)

- **Т1:** один активный таймер, без дублей точных интервалов; ручные записи имеют дату и длительность, а не часы. Предупреждение о двойном учёте и проверка дневного максимума; строгую проверку пересечений ручных сеансов не требовать.
- **Т2:** целые активные секунды, глобальный `floor(sum/60)`, детерминированная календарная детализация без потери/удвоения остатка; тесты 59+59 секунд, исправление/удаление, полночь; А1: 20 страниц с разбивкой 8+12, неизвестная разбивка, полная и частичная охваченность периода, неверная сумма, пауза без активности на соседней дате.
- **Т3:** именованная фиксированная зона, фактическая длина календарного дня, переходы DST и границы реальных таймерных моментов. Без вымышленных часов для ручных записей. Правила №242–244 сохраняются.
- **Т4:** один Markdown без изображений: версионированная схема, идентификаторы, проверка структуры/связей/совместимости, безопасные размеры/парсинг, транзакционная полная замена с отменой при ошибке, уникальные имена. Обложки сознательно не входят; при восстановлении заглушки. №254 — безопасная обработка ошибки одного файла, без удаления прежних копий.
- **Т5:** источник истины — события, производные метрики пересчитываются; один диапазон на событие, объединение для уникальных, сумма для общего объёма, подтверждённое время, награды по устойчивым ключам; ручная награда однократна, хранится минимум факта выдачи, возможна адресная отмена. Тесты редактирования, удаления, повторного чтения и отсутствия дублей. А2: подтвердить 12 ноября с датой завершения 10 ноября, затем изменить точность даты на месяц/год/неизвестно — один бонус +100 за 12 ноября; отмена исключает бонус; восстановление не датирует бонус днём импорта. А3: уникальная пара ID достижения/ступень, все достижимые ступени без дублей, потеря подтверждённого порога отзывает награду, пропуск дня не уничтожает лучшую серию. Проверки §10 обязательны для будущего TEST_PLAN.
- **Т6:** надёжный фоновый таймер, обычное восстановление достоверного состояния, простое уведомление без кнопок; при неизвестном интервале ручное исправление либо отказ от незавершённой записи. Не обещать работу после force-stop. Проверка Android и A55, в том числе при отсутствии разрешения на уведомления.
