# Каталог А3 — редакция REV-01

14 ноября 2026 г. Направление «Время за книгой»/reading_time отменено D08; его прежний каталог сохранён в исторической v2.04. Новое reading_pages не конвертируется из часов. Все остальные пороги/награды сохраняются. REV-02-D07 меняет только значки на плоские контурные; страница достижений открывается из XP-карточки Статистики, остальные карточки/панели/данные прежние. Решения REV-02 утверждены, документация ещё ожидает review.

| ID / название | I | II | III | IV | V |
|---|---:|---:|---:|---:|---:|
| streak — Сила привычки, дней≥1 новой страницы |3|7|14|30|100|
| reading_pages — Страница за страницей, новых страниц |100|1000|3000|10000|30000|

Пороги включительные, 15 ступеней, 525 на направление/1575 весь каталог. Прогресс привычки — best историческая серия; обычный пропуск не отзывает её, правка истории может. Страницы — новые в каждом цикле, повтор внутри цикла 0. Прочтения — законные завершения, включая новые циклы перечитывания, исключая исторические до дневника. А2: дата фактического подтверждения завершения, независима от редактируемой даты окончания.

Дата ступени — первая доказанная календарная дата достижения, не дата пересчёта/импорта. При изменении истории заново вычислять допустимые ступени/даты/награды; недоказанное отзывать, не выдумывать даты. Уникальна пара catalogId/stage; скачок через несколько порогов начисляет каждую законную ступень 1 раз. Никакойшестойступени, секретности, редкости, новых направлений.

Прежние числовой прогресс/полоса/подробная нижняя панель всех 5 ступеней/награды/даты/сортировка коллекции/ненавязчивые сообщения сохраняются. Пересчёт/восстановление без повторных поздравлений. Собственные достижения отдельные, ручные однократные 0–600, actualXp не меняется при правке номинала; удаление карточки сохраняет законный факт, адресная отмена исключает его. Полные неизменённые правила XP-08–13/20–23/30–33 — [PRD](../../PRD.md).

Проверки всех 15 порогов−1/ровно/+1 и скачков/отзыва/импорта — TEST_PLAN, будущие, NOT RUN в REV-01. [Основание/трассировка](../decisions/REV-01-reading-without-timer.md).
