# Действующая документация публичной копии

Публичная редакция MIGRATION-01 сохраняет действующий продуктовый договор. Исторические интервью, промежуточные снимки и прежние технические отчёты не являются частью этой копии. Основные документы не заменяют друг друга.

Публичные редакционные изменения ограничены конфиденциальностью, ссылками, реестром/суммами, текущим статусом и CI. Старые строки/суммы источников не подтверждают эту копию. Приложение А UI_DESIGN_SPEC нормативно и сохранено; исторический реестр §11 спецификации исключён, действующие требования сохранены во всех профильных разделах. Бинарные файлы ограничены двумя лицензированными шрифтами и Gradle Wrapper JAR.

После разрешённого изменения документации обновить суммы:

```sh
python3 .github/scripts/verify_docs.py --write
python3 .github/scripts/verify_docs.py
```

Манифест включает семь корневых документов, все Markdown в docs и FILES.txt; сам SHA256SUMS.txt в себя не входит. При изменении состава сначала обновить FILES.txt. Суммы являются контролем целостности, не электронной подписью и не заменой review.
