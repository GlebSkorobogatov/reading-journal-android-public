## Контроль целостности

[FILES.txt](FILES.txt) — полный список отслеживаемых файлов репозитория, [SHA256SUMS.txt](SHA256SUMS.txt) — семь корневых Markdown, все Markdown docs и FILES.txt. Манифест не включает собственную сумму и не заменяет review. После разрешённого добавления документов сначала добавить новые пути в индекс и обновить FILES.txt из `git ls-files`, затем:

```sh
python3 .github/scripts/verify_docs.py --write
python3 .github/scripts/verify_docs.py
git diff --check
```

Изменения REV-01 исключительно документационные; код/ресурсы/тесты/Gradle/manifest/CI/workflows/policy не затрагиваются. APK в этом задании не требуется. После разрешённого merge PR №3 проверить main и его штатный CI и остановиться. Переработка UI-02/UI-03 не разрешена.
