# ADR-08 — Один Markdown и атомарное восстановление

> Публичная редакция MIGRATION-01 от 13 ноября 2026 г.: обновлены структура источников и контроль целостности; действующий продуктовый договор не изменён. Текущий статус реализации — в README.md.


**Дата фиксации:** 12 ноября 2026 г.
**Статус:** Контейнер утверждён; wire-format, лимиты и активный draft — технические вопросы.
**Источник:** [ARCHITECTURE.md v1.1](../../../ARCHITECTURE.md), §§10.2–10.4; [PRD.md](../../../PRD.md); [спецификация v2.04](../Читательский_дневник_спецификация_v2.04.md).

## Контекст и решение

Один незашифрованный Markdown без обложек, строгий версионированный machine payload JSON как предложенная структура, SAF, проверка до атомарной полной замены.

## Границы и отвергнутые подходы

Не делать ZIP/отдельную папку для пользовательской копии, не перезаписывать старые копии, не считать неизвестный draft завершённым.

## Последствия и проверка

Задачи: F-13, F-14, F-15. Roundtrip, повреждение/версия/отмена, откат, уникальные имена, заглушки, факты и lock зоны.

Этот ADR извлечён из утверждённой архитектуры и не является новым продуктовым выбором или доказательством работы кода. При реализации уточнить конкретные технические параметры в пределах разрешённой задачи, зафиксировать результаты, не менять пользовательское поведение без согласия.
