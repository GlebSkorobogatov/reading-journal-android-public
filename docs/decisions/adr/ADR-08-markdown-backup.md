# ADR-08 — Один Markdown и атомарная замена

Редакция 2.0 · 14 ноября 2026 г. · REV-01. Пакет документации принят владельцем без замечаний 14 ноября 2026 г. Предыдущая редакция от 12 ноября сохранена в Git принятой базы `4c14b5dce1b9dc819d76c5c6368236320c442c3c`.

## Решение

Один незашифрованный Markdown без обложек, ZIP и автоматических копий. Строгий версионированный машинный JSON-блок остаётся архитектурным направлением; точный wire-format — будущая задача. Сохраняются ReadingRecord с точными датами, полными исходными диапазонами и порядком/происхождением подтверждений, опора, независимая закладка/рубеж, зона/lock, факты А2/личных наград и остальные данные. SAF, уникальные новые имена, проверка схемы/связей/версии/checksum до полной атомарной замены. Ошибка/отмена сохраняет прежнюю историю; успех даёт заглушки. Без слияния, частичного импорта, обязательной страховочной копии и preview счётчиков. Отменённые TimerDraft/PageOnlyEvent/А1 не входят в новый формат; минуты не превращаются в страницы.

Полный контракт — [ARCHITECTURE 2.0](../../../ARCHITECTURE.md), основание — [PRD](../../../PRD.md) и [REV-01](../REV-01-reading-without-timer.md). Физической схемы и реализации здесь нет; не добавлять сложный редактор истории или новые продуктовые решения.
