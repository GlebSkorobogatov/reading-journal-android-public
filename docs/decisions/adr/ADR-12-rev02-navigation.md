# ADR-12 — UI-контракты навигации REV-02

23 ноября 2026 г. **Статус:** документационная редакция для review; продуктовые решения [REV-02](../REV-02-ui-navigation.md) утверждены, реализация/merge не разрешены. Основание — D01–D08/A01–A03, [PRD2.1](../../../PRD.md), [ARCHITECTURE§3](../../../ARCHITECTURE.md#3-контракты-ui-и-навигация--rev-02). Дополняет ADR-01/10, не заменяет принятую историю UI-01.

## Контекст

Прежний Home в непринятом PR №4 объединяет активные книги, крупный XP, отдельные метрики, chips периодов и аккордеон. Владелец перенёс аналитику в самостоятельный корень, достижения сделал дочерними. Старый PR сохраняется read-only как источник компонентов, без переноса кода в REV-02.

## Документированное решение

- Один прежний Activity/Navigation Compose каркас, три логических корня CurrentlyReading / StatisticsOverview / Library. Холодный старт CurrentlyReading. Никакого нового фреймворка, модуля, обязательного переименования Kotlin-классов или второго нижнего navigation bar.
- Четыре дочерних направления StatisticsOverview: Achievements по XP; ReadingDynamics / ActivityCalendar / ReadingRecords по трём компактным ссылкам. Сравнение содержится в dynamics. Сведения книги/три книжные вкладки/форма/редакторы/Settings сохраняются.
- UDF, immutable UiState, ViewModel/StateFlow, stateless UI и typed ID-события. Выбранный период одного обзорного UI-контекста передаётся дочерним страницам по применимости. У календаря свой полный year, глобальные XP/серия не фильтруются. Нет второго store/баланса/дублированного calculator.
- Back из вторичного корня на первый адаптирует реально принятый UI-01 (JournalApp.BackHandler); Back из дочернего в источник/период/scroll, из книжной статистики в динамику. Вход именно из библиотеки остаётся Чтение сверху. Текущий book visit и его независимые scroll anchors по NAV-09–11 сохраняются при фоне/повороте.
- Ограниченный SavedStateHandle с ID/периодом/якорями, без всей книги/истории/картинок. Отменён expandedSection; его возможная будущая миграция техническая, не повод менять модель страниц/XP или физическую Room-схему в REV-02. Временный UI не резервная история.
- UI-02 содержит два первых demo-экрана/новую навигацию и явные заглушки будущих направлений. UI-09 реализует полные три аналитические страницы, UI-12 полную Achievements, UI-03 Library; gates не смешиваются.

## Сохранённое и пределы

Стек/данные/Room-проекции/страницы/даты/XP/уровни/награды/Markdown неизменны. Нетронутые точные токены прежние; изменяются только явно утверждённые состав/иконка/буква заглушки/плоские значки. Q01–Q03 остаются малыми будущими UI-деталями, не новыми продуктовыми решениями. Физический граф классов/векторные path/адаптивная геометрия не проектируются здесь.

## Проверка

REV2-T01–22, прежние REV-T01–27 и AC/NFR по TEST_PLAN; особенно entry/Back/период/scroll/recreation/semantics/один источник и обе темы/fontScale/поворот/A55 в будущих UI. Сейчас только документационные проверки, CI-script unit tests и Quick Draft PR; Android/ресурсы/тесты исполняемого приложения не меняются. ADR не является доказательством реализации или приёмки новой структуры.
