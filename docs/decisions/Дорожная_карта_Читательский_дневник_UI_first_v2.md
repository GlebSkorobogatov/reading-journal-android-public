# Дорожная карта UI-first — публичная редакция

Сохраняет утверждённую последовательность дорожной карты v2.0. Устаревшие продуктовые примеры заменены ссылками на действующий договор v2.04; новые функции не утверждаются. Полные scope/запреты каждой задачи — в [IMPLEMENTATION_PLAN](../../IMPLEMENTATION_PLAN.md), оракулы — в [TEST_PLAN](../../TEST_PLAN.md).

DOC → REPO → UI-01 → UI-02 → UI-03 → остальные UI → UI-READY → функциональная фаза → FUNCTIONAL-READY → QA → REL. Для каждой задачи отдельная ветка, проверки, ручная приёмка и решение владельца.


Все задачи в таблице — **утверждённая декомпозиция** уже утверждённого объёма, а не новые функциональные требования. Зависимость по умолчанию: предыдущая задача принята и зафиксирована; границы каждого gate обязательны. Список не является числом обязательных PR: исправления и согласованные мелкие подзадачи могут увеличить число. Не сокращать требования ради фиксированного числа PR.
