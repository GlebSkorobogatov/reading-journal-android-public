## 1. Договор и границы

Читай в своём темпе. Записывай прочитанное, а не измеряй процесс чтения. Личный офлайн Android/Kotlin/Compose-дневник без встроенной читалки, сервера/аккаунта/синхронизации/телеметрии. Таймер, даже дополнительный, и вся продолжительность/скорость чтения исключены. Календарные даты/зона и технические временные метки сохраняются. Нетронутые дизайн-токены утверждены и не перепроектируются; только явно перечисленные UI-изменения REV-02 разрешены документально.

Эта редакция фиксирует согласованные решения [REV-02](REV-02-ui-navigation.md) и сохранённую модель [REV-01](REV-01-reading-without-timer.md), не реализацию. Полные нормативные формулировки с устойчивыми ID — [PRD2.1](../../PRD.md), §§2.1–2.10, неотъемлемая часть спецификации; второй расходящийся каталог не создаётся. Восемь решений/дополнения/карта перемещения/исключения и статус приёмки — реестр REV-02. Принятая v3.0 доступна на базовом main и локально как исторический источник; её страницы/даты/XP обязательны, прежняя UI-структура заменена явно. v3.1 и весь документационный пакет REV-02 приняты владельцем без замечаний 23 ноября 2026 г.; изменения продуктовых решений при фиксации статуса запрещены.

## 2. Сущности и учёт

Книга с четырьмя статусами, обложкой/библиографией/тегами содержит циклы. У книги≤1 незавершённый цикл; повторное прочтение после явного завершения создаёт новый. Заметки/цитаты относятся к книге, отзыв/оценка к циклу. Независимы закладка, рубеж, начальная/подтверждённая опора и карта.

Единая запись чтения: bookId/cycleId, точный день, один достоверный исходный диапазон, устойчивый порядок подтверждения. Нет разделения на сеансы/события. p→q подтверждает p+1…q при q>p; опора на момент сохранения, не календарный предшественник. Начальная 180→200=20, а 1–180 не подтверждены. Закладка назад не меняет опору; нижний диапазон через карту, карта не откатывает опору. Обе кнопки «Записать чтение» открывают одну компактную форму: страница/дата/явный toggle/сохранение. Toggle сегодня on, прошлое off, не изменяет активную закладку из старого цикла.

Каждая страница учитывается один раз за цикл. Частичный overlap даёт только новые страницы, repeat-only не создаёт отдельную запись. Исходный диапазон сохраняется полностью. Для календаря страница принадлежит первой сохранённой всё ещё подтверждающей её записи.12 ноября 121–150, потом 10 ноября 111–130 →30 на 12-е, 10 на 10-е. Удалить первую →оставшаяся 111–130 даёт 20 на 10-е, не теряет пересечение. Дата не меняет приоритет сохранения; новые участки правки не получают прошлый приоритет. Все проекции пересчитываются атомарно, соседние исходные диапазоны не изменяются.

## 3. Даты и исправления

Дата по умолчанию сегодня в фиксированной зоне; любой прошедший точный день допустим, будущий запрещён. Обычная запись всегда точнодатирована. Исторические завершения имеют DAY/MONTH/YEAR/UNKNOWN, без выдуманных дней; исторические страницы без точного дня не создавать до уточнения. Само историческое завершение не даёт страниц/XP/серии/достижений.

TZ-01: первый конкретно датированный факт учёта закрепляет именованную зону транзакционно; удаление не разблокирует, restore заменяет zone/lock, системная смена не переносит историю. Простые технические даты книги/тега/заметки сами не закрепляют.

Существующие просмотр/edit/delete/подтверждения сохранены, новой системы исправлений нет. Независимая закладка защищена ревизией, удаление не угадывает прежнюю позицию. Изменение pageCount использует прежний утверждённый атомарный мастер конфликтов всех циклов/заметок/диапазонов; никакой молчаливой обрезки или автозавершения.

## 4. XP и достижения

1 новая страница=1 XP за цикл, +100 за действительное завершение по А2 (фактическая дата подтверждения, не редактируемая дата окончания), встроенные ступени и личные однократные 0–600 — четыре источника. Повторы/пересчёт/restore не дублируют. Исторические завершения не награждаются.

Цена перехода 200+50×(L−1); накопленный порог 25×(L−1)×(L+6). Прежние звания/пороги/степени/единый XP без балансировки и XP за звания; компактное представление XP по §5.

| Направление | I | II | III | IV | V |
|---|---:|---:|---:|---:|---:|
| Сила привычки, дней с≥1 новой страницей |3|7|14|30|100|
| Страница за страницей, новых страниц |100|1000|3000|10000|30000|
| Путь читателя, действительных завершений |1|5|10|25|50|
| Награда XP |25|50|100|150|200|

Всего 525 на направление, 1575 каталог. Лучший streak сохраняется при обычном пропуске, недоказанные ступени отзываются при правке. Числовой прогресс/полосы/нижние панели/даты/идемпотентность/ненавязчивые сообщения сохранены. Новые игровые механики запрещены.

## 5. Три основных экрана и дочерние страницы

Ровно три пункта нижней навигации: **Читаю сейчас / Статистика / Библиотека**. Холодный запуск первый, Settings по прежней шестерёнке. У первого пункта закрытая вертикальная ровная книга строго сверху, без наклона/перспективы; прежняя активная линия.

Читаю сейчас: точный заголовок и **«Не количество страниц, а глубина понимания.»**, все активные книги вертикально, pin/ручной порядок закреплённых, остальные по активности, прежние карточки/прогресс/действия/общая форма Записать чтение. Никаких XP/уровней/званий/метрик/аналитики/рекордов/аккордеона/посторонних блоков.

Статистика: компактная XP-карточка с уровнем/званием/total XP/прогрессом → одна общая горизонтальная карточка **Страницы / Прочтения / Серия**, равные области/тонкие вертикальные разделители/полные semantics → период **←    30 дней    →** → ровно три компактных перехода **Динамика чтения / Календарь активности / Рекорды**. Все шесть периодов прежние по порядку, переключаются соседними стрелками; без chips/dropdown/menu/самовольной цикличности. Глобальные XP/серия неизменны; крупный шрифт не оправдывает уменьшение типографики/скрытие/обрезку. Конкретные UI-детали Q01–Q03 — реестр, не новые макеты.

Нажатие XP открывает отдельную Achievements с прежними уровнями/званиями/встроенными/личными/прогрессом/наградами/историей. Нижней вкладки достижений нет; один XP. Плоские контурные различимые значки тонкими линиями, прежние цвета, без объёма/металла/рельефа/свечения; пороги §4 неизменны.

Динамика: прежние новые страницы/столбцы/День-Неделя-Месяц/интервалы/детали, сравнение всех Читаю включая 0 здесь же, прежними горизонтальными столбцами по страницам убывающе, переход в статистику книги/итоги завершённых циклов. Календарь: полный годовой heatmap, scroll/годы/день по книгам; прежние пять уровней **0/1–9/10–24/25–49/50+**, без времени. Рекорды: четыре — день/месяц по страницам, длиннейшая серия, книга с максимумом страниц; прежние периоды/историческая неизвестность. Полные графики не дублируются в обзоре, аккордеон отменён; радар/месячный календарь/скорость/прогноз не возвращаются.

Библиотека — третий пункт, все книги/4 статуса/теги/поиск/фильтры/сортировки/сетка-список/ручной порядок/управление. Никаких новых папок/коллекций/полок. Без обложки везде первая буква названия, прежние форма/палитра/пропорции; настоящий cover целиком Fit, без онлайн-поиска/выбора стиля.

Книга сохраняет **Чтение / Статистика / Записи**. Книжная Статистика — прежняя длинная раскрытая вкладка, все/один цикл, страницы/записи/прогресс/динамика/heatmap/карта/итоги. История страниц/точных дат во вкладке Чтение. Общая статистика и статистика книги различимы. Back из дочернего возвращает к источнику/периоду/scroll, из сравнения к конкретной книжной статистике и назад; NAV-09–11 посещения книги/поворота/фона сохраняются. Второй нижней навигации и второго store нет.
